## 🔄 PROTOCOLO DE INICIO DE SESIÓN

### Cada vez que inicies una jornada:
1. **mem_context** → Ver historial reciente
2. **Verificar fecha** → Comparar con cronograma
3. **Calcular avance** → Esperado vs real
4. **Recomendar acciones** → Específicas para el día

### Alertas automáticas:
- **1-2 días atrasado:** Simplificar tareas, priorizar MVP
- **3+ días atrasado:** Revisar alcance, reducir features
- **Adelantado:** Mantener ritmo, pulir calidad

## 🎯 RECOMENDACIONES CLAVE

### Para los 3 proyectos:
1. **NO más de 1 hora de teoría por día**
2. **Commit diario** aunque sea pequeño
3. **Tests primero** antes de código complejo
4. **Documentación incremental** no dejar para el final
5. **Pide ayuda temprano** si algo toma más de 2 horas

### Por proyecto:
- **Call Me Maybe:** Completar fases 2-7, no perderte en detalles de ML
- **Flying:** Parser → Simulación → Pathfinding, BFS primero
- **Codection:** No aprender concurrencia desde cero, usar recursos existentes

4. Documentar lección aprendida
